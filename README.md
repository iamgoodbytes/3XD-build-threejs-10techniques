# Three.js les: van groene kubus tot eindeloze game

```bash
npm install
npm run dev
```

Open http://localhost:5173. De overzichtspagina linkt naar elke stap (`stap1/` … `stap8/`).

- [LESSENPLAN.md](LESSENPLAN.md): het lessenplan voor de lesgever (verloop, timing, oefeningen, veelgemaakte fouten).
- [CONCEPTEN.md](CONCEPTEN.md): naslagwerk voor studenten. Per techniek: wat, hoe het werkt, recept en valkuilen.

**Slides in elke demo:** klik onderaan op *Toon achterliggende techniek* (of druk **T**). De demo pauzeert en je ziet per stap hoe het werkt, met de echte code. Pijltjes/spatie = volgende slide, cijfers = onderdeel uit de inhoudstafel, **Esc** = terug naar de demo. Direct openen kan via de URL, bv. `/stap2/#techniek-5`.
De inhoud staat in [slides/content.js](slides/content.js). Wijzig je de code van een stap, controleer dan of de fragmenten nog kloppen met `node slides/check-snippets.mjs`.

Modellen: [Kenney Car Kit](https://kenney.nl/assets/car-kit) (CC0) in `public/carkit/`.
